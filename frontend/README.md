# ColdGuard Frontend

This directory contains the React frontend for the ColdGuard application.

The frontend was built using:

- React
- Vite
- React Router
- Bootstrap 5
- Fetch API

It provides the user interface for:

- Login
- Inventory dashboard
- Temperature monitoring
- Threshold management
- Alerts
- Reports
- Temperature insights
- AI Risk Advisor

For full project documentation, setup instructions, deployment links, and screenshots, see the root `README.md`.
